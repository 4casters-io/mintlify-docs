# 4Cx API documentation

Mintlify site for the public 4Cx REST and Streaming APIs.

**Source of truth:** `4cx-fourcasterapi/artifacts/pro-161/4Cx API.postman_collection.json` — update the Postman collection first, then sync these pages.

## Local preview

```bash
npm i -g mint
cd mintlify-docs
mint dev
```

Open http://localhost:3000

## Validate

```bash
mint validate
```

## Deploy

Connect this repo in the [Mintlify dashboard](https://dashboard.mintlify.com). Pushes to the default branch deploy automatically when the GitHub app is installed.
