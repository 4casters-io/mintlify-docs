# Place coins orders

There is no separate endpoint for coins orders. You use the same [Place order](/pages/orders/place-order), [Cancel order](/pages/orders/cancel-order), and [List my open orders](/pages/orders/list-open-orders) routes for every order on the platform. **The denomination is determined entirely by your account's current player mode.**

<Note>
  - When your account is in **Gold Coins mode** (`coins`), every order you place is denominated in **Gold Coins**.
  - When your account is in **Sweepstakes mode**, every order you place is denominated in **4C cash**.
</Note>

<Warning>
  **Gold Coins mode is take-only.** In `coins` mode you can only **take** existing liquidity — you cannot create offers on the book. `orderType: "post"` will not create an offer, and [List my open orders](/pages/orders/list-open-orders) is always empty. Creating offers (and therefore open orders) is a **Sweepstakes-mode** feature. To create offers, switch to Sweepstakes mode first.
</Warning>

There is no per-request flag that overrides this — the mode is a single per-account setting. To trade in the other currency, switch the mode **before** placing the order.

## How to switch

Call [Switch player mode](/pages/coins-only/switch-player-mode) with `{ "playerMode": "coins" }` or the Sweepstakes-mode value shown on that page.

You can confirm the current mode at any time by inspecting `data.user.playerMode` from the [Log in](/pages/authentication/log-in) response, or via `/user/getMe`.

## Then place your order

Once your mode is set, follow the standard order flow:

- [Place order](/pages/orders/place-order) — in **Sweepstakes mode**, both `post` and `limit` can create an offer (`post` creates only; `limit` takes first, then can create an offer with any remainder). In **Gold Coins mode**, offer creation is unavailable.
- [Cancel order](/pages/orders/cancel-order) — cancel a single open order.
- [List my open orders](/pages/orders/list-open-orders) — your unmatched open offers.

Switching modes does **not** auto-cancel orders that are already open in the previous mode; only newly placed orders are affected.
